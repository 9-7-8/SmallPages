playlist → audio

Paste a YouTube or YouTube Music playlist, pick a quality tier, and copy the yt-dlp command. The downloading happens on your machine — a web page can't pull YouTube streams itself, and anything that claims to is routing your request through someone else's server.

Needs yt-dlp and ffmpeg on PATH. Update first: py -m pip install -U "yt-dlp[default]"  ·  ffmpeg: winget install Gyan.FFmpeg

    When it doesn't work
    
“Requested format is not available” or a signature error. YouTube changed something. Update yt-dlp — py -m pip install -U "yt-dlp[default]" — before assuming anything else is wrong. This is the cause most of the time.

    
“ffmpeg not found”. Every tier here re-encodes, so ffmpeg is not optional. Install it and open a fresh terminal so PATH refreshes.

    
A private playlist, your Liked Music, or an age-gated video. Set the cookie option to the browser you're signed into. Close that browser first — Chrome and Edge lock their cookie database while running.

    
Everything stalls partway through a long playlist. Leave “Go slowly” on and re-run. The archive file means it resumes where it stopped instead of starting over.

    
Tracks are tagged oddly. YouTube Music playlists carry real artist and album metadata; plain YouTube playlists mostly don't, so tags get built from the video title. Nothing to be done about that at the download stage.

    
A note on what you point this at. Fine for your own uploads, Creative Commons and public-domain material, and things you already hold a licence to. Ripping a commercial music catalogue is something else, and no flag in this builder changes that.
