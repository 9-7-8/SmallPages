SmallPages

Single-purpose tools that run entirely in the browser. Nothing uploads anywhere.

  • gif → mcmeta animated texture strip for Minecraft
  • minecraft item pad to square, then every texture size
  • png → swirl gif spin a still image into a loop
  • image → svg trace a bitmap to vector shapes or lines
  • remove background cut the subject out of a photo
  • palette → gem grow a faceted stone from a palette
  • unified palette cross-mix colours into a set that agrees
  • playlist → audio build the yt-dlp command for a playlist
  • anything → image paste or drop anything, get a picture of it
  • unzip open a zip and pull files out of it
