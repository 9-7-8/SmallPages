Markdown → Rich Text

Paste Markdown on the left and watch it set itself on the right. The Copy button puts the formatted version on the clipboard — paste it into Word, Google Docs, an email or anywhere else that takes rich text and the headings, lists, tables and bold arrive as headings, lists, tables and bold rather than as the characters you typed round them. Or take it away as a file.

Markdown
Preview

The preview is built from the characters you typed and never runs them: HTML written in the Markdown shows as the tags themselves, and a link whose target is anything but an ordinary address is dropped rather than carried along to wherever the text is pasted. Download .md is the source exactly as it stands; .txt is the preview flattened — no asterisks, bullets as bullets, tables lined up in columns — which is the same plain text the clipboard carries alongside the formatted version, so pasting into a plain box gives you that rather than the markup. Two things it cannot do: a | inside a code span splits the table cell it is in, and copying needs the page served rather than opened off the filesystem on some browsers — it falls back to selecting the preview for you, and says so if even that is refused.
