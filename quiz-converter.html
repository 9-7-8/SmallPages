There is no universal format, and this is the nearest thing to one. Anki is the only one of these that genuinely exports: a .apkg is a zip with a SQLite collection inside it, and it is all there, note types and field names included. Quizlet exports too, as text with separators you choose. Blooket, Wayground and Gimkit are import-only as far as their own documentation goes — they take a spreadsheet and give nothing back. So the way round is CSV: this page writes the layout each one asks for, and reads any of them back in again, which means the CSV you made for Blooket last term is a perfectly good source for Gimkit today.

The column layouts are a best reading, not a specification. None of the three publishes its template as documentation; what is here was assembled from their help pages and from third-party guides in October 2026, and a site can change its template without telling anyone. If an upload is refused, download that site's own template, compare it with the Plain table output, and move the columns about — the plain one exists for exactly that. Where they are known to differ this page follows the site's own help page over a guide.

Wrong answers are picked to be plausible. The script this came from compared the right answer against every other answer in the deck by Levenshtein distance, preferring ones of the same length, so that the decoys look like something you might confuse the answer with rather than something obviously from another part of the deck. That is kept here, and made faster: candidates are bucketed by length first and the distance is abandoned as soon as it exceeds the best already found, which is what makes five thousand questions a second rather than a minute.

Only the older Anki package format can be read. Since 2.1.50 Anki compresses its collection with Zstandard and calls it collection.anki21b; before that it was a plain SQLite file in the zip. Reading the new one would mean carrying a Zstandard decoder for one file format, so instead this says so plainly when it meets one. In Anki, File → Export with Support older Anki versions ticked writes the readable kind.

The SQLite reader is this page's own. It reads the file format directly rather than carrying a database engine for one table: the page header, the b-tree, the record encoding and the overflow pages a long note spills onto. It was checked against sqlite3's own output over a five thousand note deck, field by field, and the two agree exactly.

It runs here. Nothing is uploaded, and a 90 MB package with ten thousand audio files in it is never read whole — the zip's directory is read from the end of the file and only the collection is pulled out, so the media never touches memory.
