Laps

It counts from the clock, not from its own ticks. The running stretch is the difference between two timestamps rather than a count of frames, so a tab the browser throttles, a phone that locks, or a window left behind another one for an hour all come back showing the right number. The reading is redrawn as often as the screen refreshes while it is going, and not at all while it is stopped.

A reload does not stop it. Whether it is running, how long it had already run, and when the current stretch started are kept in this browser, so closing the tab and opening the page again finds the stopwatch where you left it — still going, if it was going. The laps come back with it. Reset is the only thing that clears it, and it asks for nothing: press it twice if you meant it, because the first press stops the watch.

A lap is both figures. Every lap carries the time since the previous lap and the time since the start, because the two answer different questions and a list of only one of them is half a list. Once there are three laps the quickest and the slowest are marked, and the bars underneath draw each lap against the longest one, which is where the shape of a set of laps actually shows — a run that is drifting slower looks like a staircase long before the numbers say so.

Hundredths, and no further. A browser hands out time in milliseconds and rounds what it gives a page on purpose, to make it harder to fingerprint, so a figure past the hundredth would be inventing precision the clock does not have. Copy writes the laps out as tab-separated columns — lap number, lap time, split, and both in milliseconds — which pastes straight into a spreadsheet.
