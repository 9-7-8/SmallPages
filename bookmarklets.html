My bookmarklet

A bookmarklet is a bookmark whose address is a program. Where an ordinary bookmark holds https://…, this one holds javascript:… — the whole program, URL-encoded, in the address field. Clicking it runs that program against the page you are on, with the same access the page's own scripts have and none of the installing, permissions or updating an extension needs. Nothing here is fetched at run time: what you drag is the whole of it.

Drag them, do not click them. Clicking one of these buttons on this page would run the applet here, against this page, which is never what was meant — so a click is caught and told to drag instead. Drag the button onto your bookmarks bar, or use Copy the bookmarklet and paste it into the address field of a bookmark you make by hand. In Firefox that is right-click the bar → Add bookmark; in Chrome, right-click → Add page, and paste into URL.

Write them without innerHTML. YouTube, GitHub and a growing number of other sites set require-trusted-types-for 'script', which stops a page assigning a string to innerHTML at all — so a bookmarklet that builds its panel that way dies silently on exactly the sites worth writing one for. Build the panel with createElement, textContent and append instead. The applet above does, and a check in this repo's tests fails if one ever stops doing so.

There is no length limit worth worrying about, but there is a limit. Firefox and Chrome take bookmarklets of tens of kilobytes; the one above is a good deal longer than anything you would write by hand and installs fine in both. Some older browsers and some bookmark-syncing services truncate long URLs without saying so, which shows up as a bookmarklet that does nothing. The encoded size of each one is printed next to it so you can see what you are asking a browser to hold.

Adding another one here. Put its source in a <script type="text/plain" id="src-<name>"> block at the foot of this file and add an entry to the APPLETS list in the script under it — an id matching that block, a name, a line saying what it does, the steps to use it, and whatever has to be said about what it cannot do. Everything else, including the encoding, the drag button and the source listing, is built from that. Two rules the source has to keep: no </script> anywhere in it, because the block holding it is raw text and would end early; and no innerHTML, for the reason above. Both are checked by tests/test-applets.mjs.

Everything here happens in this tab. The encoding is encodeURIComponent and the syntax check is the browser's own parser, by way of new Function, which compiles the code without running any of it. Nothing you paste is executed, stored or sent anywhere.
