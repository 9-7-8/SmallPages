Discord

The server is not on a timetable. It is off until somebody asks for it, and anybody can ask — type /start in Discord and it comes up. Nobody has to wait for Isabel to be at her desk.

The server takes itself down after an hour with nobody on it. That is not a punishment, it is the electricity bill — and it is why bringing it back up has to be something you can do yourself. If it is down, that is normal. Start it.

What anyone can run

  • /startBring the server up. The first one each day also runs the full morning chain, so give it a few minutes; after that it is a plain boot. Either way it takes a couple of minutes — this pack has never booted in under 143 seconds
  • /stopShut it down cleanly. It refuses while anybody is online, so you cannot end somebody else's evening by accident
  • /statusUp or down, who is on, and how the server is performing
  • /playersWho is online right now
  • /tpsPerformance in ticks. Below 20 means the server is working hard
  • /linksThe pack download, this handbook and the live map, so you never have to find the addresses again
  • /helpThe same list, from the bot itself, which is always the current one

What needs the role

Four of them change the world for everybody else, so they sit behind a Discord role. Ask Isabel if you want it.

  • /difficultyPeaceful, easy, normal or hard
  • /timeDay, noon, night or midnight
  • /weatherClear, rain or thunder
  • /stop force: TrueStop the server while people are on it. The only genuinely rude button on the bot

The bot cannot read anything you type. It has no message permissions at all — only the slash commands above ever reach it. It cannot pass a message to Isabel, to the server, or to anyone in game. If you want to say something in game, say it in game; to reach Claude, see Asking Claude.

It posts as well as listens. Server up and down, the nightly performance digest, new pack versions and new Horse Genetics builds all arrive in the channel without anyone asking.

If nothing happens

A slash command that times out usually means the bot itself is not running, which is separate from the server being down — the bot is what starts the server, so if the bot is out nothing can bring it up remotely. Say so in the channel; it needs a hand at the machine. And if /start reports success but you still cannot connect, give it another two minutes before assuming anything: the chain is long and the Minecraft port opens last.
