Uptime

One cell per hour, newest day last. Every cell is evidence rather than a guess: the server writes a performance sample every five minutes, so an hour is green only because something actually answered in it.

“No data” is not the same as “down”. The sampler runs on the same machine as the server, so when the machine is asleep or logged out nothing is recorded and nobody was watching. The server was certainly not reachable, but it was never seen to fail — so those hours are hatched rather than red. They still count against the uptime figure.
