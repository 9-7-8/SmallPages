Sorting chests

The first real problem in a pack this size isn't finding things — it's that an hour of mining and looting leaves you with eleven chests of unsorted rubbish. SortCraft fixes that with signs. No redstone, no hoppers, no machines, and you can build it on your first day with wood and a few chests.

This is a day-one tool, not an endgame one. Once you have an AE2 or Refined Storage network running, that replaces it completely. SortCraft is what gets you through the many hours before then.

Build it in three steps

  1. Put chests down and label each one with a sign.

    Place a chest, then put a wall sign on the side of it, and write a category name in square brackets on any line: [ores], [food], [wood].

    It has to be a wall sign — one stuck to the side of the block. A standing sign on top of the chest does nothing, and neither does a hanging sign: SortCraft finds the chest by looking at what the wall sign is attached to, and those two aren't attached to anything. This is the single most common reason a chest never fills.

    All four lines are read, front and back, so the other lines are yours to label with.

  2. Put down one more chest and label it [input].

    This is the bucket you dump everything into when you get home. It doesn't need to be next to the others — see the range note below.

  3. Dump your loot in, then right-click the [input] sign.

    Everything that matches a category flies to the right chest. Anything with no matching category stays in the input chest, so nothing ever goes missing.

    Shift + right-click the same sign to preview instead — it tells you what would go where without moving anything. Worth doing the first time so you can see your layout working.

How close do the chests need to be?

They don't need to touch. Nothing has to be adjacent to anything else — not the destination chests to the input chest, and not the destination chests to each other. Everything just has to be within 16 blocks of the input chest, which is a generous room.

The only thing that must physically touch is each sign and its own chest. Beyond that, put the chests wherever they look good: two walls of a storage room, both floors of a tower, scattered around a basement. The input chest can sit by your front door with everything else a corridor away.

One sign per chest, one chest per category. Double chests count as a single chest, so a double chest is the easy way to give a busy category more room.

What counts as a chest

Anything that holds items, not just wooden chests. Barrels work, Sophisticated Storage barrels and chests work, and Functional Storage drawers work — and drawers are worth a section of their own, below.

Drawers, and one sign for a whole column

A sign labels the container it is stuck to and every storage block directly underneath it. SortCraft walks straight down from the signed container and keeps going until it hits something that isn't storage, or a container that carries a sign of its own.

That is what makes drawers work properly. Put a Functional Storage drawer down, sign it [ingots], then stack five more drawers below it — no more signs — and that one category now has six drawers' worth of room. A drawer holds one item type per slot in enormous quantity, so this is far and away the best home for the bulk categories: [ingots], [stone], [wood], [crops].

  1. Build the column downward, not sideways.

    The sign goes on the top container. Anything beside it is a separate chest that needs its own sign.

  2. Seed the drawers before the first big sort, or lock them.

    An empty drawer slot takes whatever arrives first and then only accepts that one item. SortCraft asks each slot whether it will take an item and never forces a wrong one in — but it does mean the first sort decides what each slot becomes. If you want a particular layout, put one of each item in by hand first, and a lock upgrade keeps it that way even when the drawer empties.

  3. If it's full, nothing is lost.

    Items with nowhere to go stay in the input chest. They are never dropped or destroyed.

Barrels and Sophisticated Storage chests stack the same way, so you can mix them in a column.

Shulker boxes in the input

Drop a shulker box or a bundle into the input chest and SortCraft empties it and sorts what was inside, which makes a shulker box the natural way to carry a mining trip home in one slot.

The exception is a box that holds ten or more stacks of the same thing. That reads as deliberate storage rather than luggage, so the box is filed whole, as an item, instead of being unpacked.

Start with six chests

There are 57 categories, plus one for every mod in the pack, but you do not need to care about that yet. Sign six chests with these and you have covered nearly everything the game will throw at you:

  • [ores]Ore, raw metal, ingots, nuggets, gems, dust, coal and metal blocks
  • [food]Anything edible, plus drinks
  • [gear]Every weapon, tool, shield and piece of armour
  • [bulk]Stone, dirt, sand, wood, glass, stairs, slabs — building material
  • [farming]Seeds, saplings, crops, bonemeal
  • [loot]Mob drops, discs, sherds, heads and trinkets

Then split them when a chest fills up

This is the part worth understanding, because it means you never have to redo your storage room. Categories are arranged in tiers, and an item takes the most specific chest that exists. If you have not built that chest, it rolls up to the general one instead.

So a diamond looks for [gems], and if there is no such chest it settles for [ores]. The day [ores] gets too full, you put down a chest, write [gems] on it, and gems start going there by themselves. Nothing else changes.

[loot][mob_drops] [trophies] — and [tech] for redstone parts

[wood] and [stone] go by what a thing is made of. Anything made entirely of wood lands in [wood] — planks and logs, but also doors, fences, gates, trapdoors, buttons, pressure plates, stairs, slabs, signs, boats, bowls, ladders and sticks. Anything made entirely of stone or cobblestone lands in [stone] the same way — walls, stone stairs and slabs, furnaces. Both beat [shapes].

What a thing is FOR still beats what it is made of. A wooden pickaxe is still [pickaxes], a chest and a barrel are still [containers], and charcoal is still [coal] even though it is smelted from logs and so counts as wood quite literally. Mixed things belong to neither: a lever is cobblestone and a stick, so it stays where it was.

If you have not built a [wood] or [stone] chest, none of this changes anything — those items fall through to [shapes] and [bulk] exactly as before.

Four that sort by what happened to an item

These are checked before everything above, so they win over the ordinary category for that item type. Each one is inert until you build its chest.

  • [named]Anything you renamed in an anvil. The reason to bother: your favourite pickaxe stops vanishing into a chest with forty others. Name it once and it always comes home here
  • [damaged]Tools, weapons and armour at 25% durability or less — the repair pile
  • [enchanted]Any enchanted gear, kept away from the plain stuff
  • [enchanted_books]Exactly what it says

A chest for exactly one item

Every single item in the pack is its own category, named by its full id — the mod's name, a colon, then the item. Sign a chest [minecraft:lead] and it takes leads and nothing else.

It has to be the full id. [lead] on its own is not a category and deliberately never will be. Short names go wrong the moment two mods both add something with the same one, and every short word spent this way is a word that could never be given to a proper category later.

These beat everything. A chest signed [minecraft:diamond_pickaxe] takes every diamond pickaxe, even a renamed, enchanted or nearly-broken one, ahead of [named], [damaged] and [pickaxes]. That is the point of them — one thing you care about, always in the same place — but it does mean an item chest quietly outranks the rest of your sorting room for that one item.

Don't type them by hand. A sign line holds about fifteen characters, nowhere near enough for most modded ids. Hold the item, look at the sign, and run /signitem — it writes the id for you, split across the sign's lines so it still sits inside the sign. A name split that way sorts exactly as if it were on one line.

Not sure what something is called? /sort category <item> lists every chest name that would take it, and F3 + H turns on tooltips that show an item's id.

A chest for one mod

Any mod's own name works as a category. Sign a chest [horsegenetics] and everything from Procedural Horse Coats lands in it; [ae2], [enderio], [occultism], [railcraft] and 182 others all work the same way.

The name to write is the mod's id, which is the part before the colon in an item's id rather than its pretty name. Press F3 + H once to turn on advanced tooltips and every item shows you its id; /sort category <item> will also tell you, and it names the mod chest along with the normal one.

Mod chests are checked last, just ahead of [misc], so everything above beats them. If you have an [ingots] chest and an [enderio] chest, Ender IO's ingots still go to [ingots]. A mod chest is for the things a mod adds that fit nowhere else — machine parts, ritual components, its own oddities — not a way to pull a whole mod out of your sorting room.

[misc] catches everything else. Build that chest and nothing is ever left behind — but you also stop noticing what has no proper home. Leaving it out is the better default: unmatched items stay in the input chest where you can see them, and you can say so in chat.

Commands worth knowing

  • /sort previewShows what would move where, without moving it. Same as shift + right-clicking the input sign
  • /sort category <item>Tells you which category an item belongs to, so you know which chest to build
  • /sort whereis <item>Finds where something is already stored and highlights those chests with a glowing outline you can see through walls
  • /sort inputSorts the nearest input chest, if reaching the sign is awkward
  • /signitemHold an item, look at a sign, run this and the sign labels itself for that item. Saves typing a long id by hand. /signitem add writes into the sign's empty lines instead of clearing it
  • /sort helpThe full list

When it doesn't work

  • Nothing moved. The sign text has to match a category name exactly, brackets included — though it can be on any line, front or back. If the whole chest is ignored, check the sign is a wall sign on the side and not a standing sign on top.
  • Some items stayed behind. That's correct behaviour — they don't match any category yet. Run /sort category on one and say so in chat if it looks like it should have a home.
  • One chest never fills. Check that its sign is actually attached to that chest and not to the block beside it.
  • A chest filled up. Items that don't fit stay in the input. Make it a double chest, or point that category at a drawer.
