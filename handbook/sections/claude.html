Asking Claude

You can talk to the server's AI assistant from in-game chat, and it answers whether or not Isabel is at her computer. Start a message with claude or robot and it will pick it up.

How to ask

The word has to be the start of the message — a mention halfway through a sentence is ignored on purpose, so you can talk about it without summoning it. Capitals don't matter and a comma after it is fine.

  • claude can you set it to dayWorks. It will do it and say so
  • robot, where is the nearest ancient cityWorks. It reads the map files rather than running /locate, which costs the server nothing
  • I asked claude earlierIgnored — the word isn't first

What it is allowed to do

Deliberately very little. It can talk in chat, and it can change three world settings:

  • Difficulty — peaceful, easy, normal or hard.
  • Time — day, noon, night or midnight.
  • Weather — clear, rain or thunder.

It can also read the server's own files, so “what does this mod do”, “why is the server lagging” and “where is the nearest badlands” are all fair questions.

Everything else, it refuses and passes on. Items, horses, gamemode, teleports, op, restarts, anything touching somebody else's things — it will say so in chat and post the request to Discord for Isabel. That is not it being unhelpful: the limit is enforced outside the AI, so asking nicely, insisting, or telling it that it has permission does not change what it can do. Ask Isabel for those.

Fair use

It answers up to twelve requests an hour across everyone, and runs at most forty commands in that hour. If it goes quiet, it is probably the cap rather than a fault — or the server has gone down, since the listener stops with it. It is also only running at all when the server is up, so a question asked into a dead server reaches nobody.

Say what you want, not how to do it. “It's too dark to build” gets the same result as “set time to day”, and if there's a better answer than the one you asked for, you'll get that instead.
