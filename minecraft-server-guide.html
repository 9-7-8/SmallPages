First join

Four things to install before Minecraft will even let you knock: Tailscale, LocalSend, the right NeoForge build, and the pack itself. Follow these in order — each one depends on the one above it.

NeoForge must be 26.1.2.109 or above. This is the single most common reason a client won't start. Anything older is refused — and the error blames a mod rather than the version, so it is easy to misread.

Getting on the network

The server isn't on the open internet. It lives on a private Tailscale network, so there is nothing to port-forward and nothing for strangers to find — but you have to be let in first.

  1. Install Tailscale and sign in.

    Get it from tailscale.com/download. Sign in with whichever account you gave Isabel — Google, Microsoft, GitHub, whatever you told her. It has to be that one; the invite is tied to it.

  2. Accept the invite to the network.

    Isabel sends you a join link. Open it while signed in and accept. Tailscale's icon should then say Connected. Leave it running whenever you play — if Tailscale is off, the server simply won't appear.

  3. Install LocalSend — optional, as a fallback.

    You will normally download the pack from the link in the next step. LocalSend is worth having anyway for when that is not an option: it is free, open source, on every platform, and sends a file straight from one machine to another with no upload in between.

  4. Download the pack.

    Once Tailscale says Connected, open the download page. It only exists on the tailnet, so if it loads, your Tailscale is working — which makes it a useful test on its own.

    Take the full pack the first time. Later, when the server changes, that same page carries a small update pack instead — a few MB rather than a few hundred, and the page always lists the current one.

    If the page won't load, Tailscale isn't connected yet. Failing that, ask Isabel to send it over LocalSend instead.

    Don't unzip it yet.

Installing the pack

  1. Launch plain Minecraft 26.1.2 once.

    In the Minecraft Launcher, play version 26.1.2 with no mods, let it reach the title screen, then quit. This makes the launcher download the files NeoForge is about to build on top of. Skipping it is the most common reason the next step fails.

  2. Install NeoForge 26.1.2.109 or newer — never older.

    26.1.2.109 is a hard minimum. Mods in this pack refuse to load below it. .106 will not work, and neither will anything else under .109.

    On that page pick 26.1.2.109 (or a higher 26.1.2.x if one exists by the time you read this) and download the Installer. Run it — double-click, or java -jar neoforge-26.1.2.109-installer.jar — choose Install client, leave the path pointing at your .minecraft folder, and press OK.

    If you are below the minimum the game stops during loading and names a mod, not a NeoForge version — something like "requires neoforge 26.1.2.109 or above". That message means this step, nothing else.

  3. Make a separate installation with its own folder.

    This keeps 337 mods away from your existing worlds. In the launcher: Installations → New installation, set Version to neoforge-26.1.2.109, and set Game directory to a new empty folder — something like C:\Minecraft\isabel-server. Save it.

    If you'd rather not bother, you can skip this and use your normal .minecraft — but move your existing mods folder somewhere safe first, because the pack has to be the only thing in there.

  4. Copy all four folders in.

    Open the zip and copy mods, config, kubejs and resourcepacks into the game directory you just set. If you're asked whether to merge or replace, choose replace.

    All four matter. config and kubejs are not optional extras — several mods build their item lists from those files, so a client without them knows about different items than the server does and gets refused on connect.

    You want <game directory>/mods/ full of jars — not mods/mods/, which is the classic mistake. There should be 337 files in there when you're done.

  5. Give Java more memory.

    Still in Installations, edit your new installation, open More options, and find the JVM arguments box. Change -Xmx2G to -Xmx8G (or -Xmx6G if your machine has 8 GB of RAM total). Leave the rest of the line alone. The default 2 GB will not load this pack.

  6. Launch it, and expect to wait.

    First startup takes several minutes and looks frozen more than once. That's normal for 337 mods. It's much quicker every time after.

  7. Add the server and connect.

    Multiplayer → Add Server, then the address Isabel gives you. Check Tailscale says Connected first. The first join builds a lot of caches and can sit on "Loading terrain" for a while.

  8. Open the quest book.

    There's an FTB Quests book covering the tech and progression mods. It's the best map of the pack that exists, and it hands out starting gear. Find Open Quests in Controls if it isn't bound.

Server address: ask Isabel — it isn't written down here on purpose.

Kicked with "The server sent registries with unknown keys"? That long list of item names means your config or kubejs folder is missing or incomplete — not that a mod is broken. Go back and copy all four folders across, then relaunch.

If something in the pack misbehaves: two mods are known-shaky on some setups. If the game crashes naming lambdynamiclights, delete that one jar from mods and everything else still works. And the Shelf-Shrooms resource pack will warn that it's made for an older version — confirming past that is fine, it's optional either way.

Your first hour

Normal survival rules apply. Punch wood, make tools, don't dig straight down. The differences worth knowing on night one:

  • Death is survivable. Epitaphs places a grave where you died, holding your things. Walk back and collect it.
  • Sleeping is a group activity. You don't need everyone in bed to skip the night, but you do need enough people. Get in bed and wait a moment.
  • Check recipes in-game. JEI is the recipe viewer: hover any item and press R for how to make it, or U for what it's used for. With 337 mods this is the most useful key on your keyboard.
  • Don't build anything permanent yet. Claim first — see the next tab. Unclaimed land is not protected.

Claiming land

Land protection is handled by FTB Chunks, but you drive it from the JourneyMap fullscreen map. You claim whole chunks — the 16×16 columns Minecraft is built from — and everything inside becomes yours.

How to claim

You claim from the JourneyMap fullscreen map, not from a separate FTB Chunks screen. JourneyMap is the pack's map mod, and FTB Chunks hangs its claiming off it.

  1. Open the JourneyMap fullscreen map.

    The key is M. If that does nothing, look for Open JourneyMap Fullscreen Map in Controls — this pack ships KeybindsPurger, which strips keybinds, so don't assume the default survived. Clicking the minimap works too.

  2. Press the claim button in the UPPER LEFT of that screen.

    That is the one that turns the map into the chunk grid. It is easy to miss among the other map buttons — it is in the top-left cluster, not with the map-type or waypoint controls.

  3. Drag across the grid.

    The controls are below. You stay inside JourneyMap the whole time; the grid is an overlay on the map you were already looking at.

With the grid open:

  • Left-dragClaim the chunks you drag across
  • Right-dragUnclaim them again
  • Shift + Left-dragForce-load — keeps the chunk running while you're away
  • Shift + Right-dragStop force-loading
  • Hold TabHide the grid to see the map underneath

Dragging has three shapes, switched in FTB Chunks' client settings under Chunk claiming mode: Rectangular (the default), Circular, and Freehand. Rectangular is what you want almost always; freehand is for tracing an awkward border.

Claiming protects land. Force-loading is different and more precious: it keeps your machines ticking when nobody is nearby. Spend those on farms and power generation, not on your house.

Your limits

AllowancePer playerWhat it means
Claimed chunks500A 22×22 patch of chunks, about 350 blocks square — far more than a base needs
Force-loaded chunks25The scarce one. Budget these deliberately

These are per player, not per team. When you join a team the members' allowances pool, so two people together can claim 1000 chunks and force-load 50. Claiming works in every dimension — this server sets no dimension restrictions on it.

Do not claim the spawn village. Nothing in FTB Chunks stops you, but spawn is separately protected and is meant to stay common ground — claiming it would only lock your friends out of the shop and the stables. Build your base somewhere else and claim that.

PvP is on, including inside claims. Claims protect your blocks, not your body. This is a friendly server, so in practice it matters mostly for stray arrows and enthusiastic explosives — but a claim is not a safe room.

Teaming up

If you're building with someone, make a team rather than claiming separately. A team shares its claims, its allowances and its permissions — so you can both edit the base, and neither of you is locked out of the other's chests.

Team commands live under /team, from FTB Teams. Create one, invite the other person, they accept. Your claims merge into a shared pool from then on.

Claim before you build. Claiming after the fact works fine, but anything left unclaimed overnight is fair game for mobs and explosions even if your friends behave.

Money & shops

The currency is emeralds — actual emeralds, in your inventory. There is no balance, no /pay, and no way to buy anything from across the map. If you want to trade, you travel.

Open your own shop

  1. Craft a Shopcase.

    One emerald directly above one chest, in a crafting grid. You get an item called Shopcase.

  2. Place it where you want the shop to stand.

    Somewhere people can reach. A shop nobody can walk to sells nothing.

  3. Right-click it to open the shop menu.

    Set what you're selling, what you want for it, and how much is stocked. It's all in the menu — no commands to memorise.

  4. Stock it and leave it running.

    The shop keeps selling while you're offline, and the takings are waiting when you log back in.

Nobody can rob your shop. Only you can open its menu — anyone else clicking it just gets the buying screen. Claim the chunk it sits in and it can't be broken either.

Buying from someone else

Walk up to their Shopcase and click it. You'll see what's for sale and the price. If you have the goods you get the item; if the shop is out of stock, it says so.

Prices are set by whoever owns the shop, not by the server. Shop around — literally.

The server store

There's also a Market, a small wooden stall with a merchant in it. It sells at fixed prices in emeralds, never runs out, and isn't owned by anyone. Treat it as the price floor: if a player shop is charging more than the Market for the same thing, you're being had.

Where do emeralds come from? The ordinary places — trading with villagers, mining, exploring. Villager trading is also where they leave circulation again, so the economy roughly balances itself without anyone managing it.

Mining

This pack adds a lot of ores on top of the vanilla ones. You don't need to memorise them — two tools tell you everything as you go.

Turn these on first

Vein mining

Hold ~ and break a block. That is the tilde/backtick key immediately left of 1, on the row above Tab. Everything connected to that block breaks with it.

This is FTB Ultimine, and it is the single biggest quality-of-life feature on the server:

  • Whole trees — one swing at the trunk and the entire tree comes down, leaves and all. No jumping, no leftover floating logs.
  • Whole ore veins — hit one block of a vein and take all of it, including modded ores.
  • Tunnels, fast — hold it while digging and you carve corridors far quicker than block by block.

You will see the affected blocks highlight before you break anything, so you always know what you are about to take. It handles up to 64 blocks at once here, and eats hunger in proportion — bring food if you are felling a jungle.

If ~ does nothing, it is almost certainly unbound rather than broken: this pack ships KeybindsPurger. Open Controls, find Activate Ultimining under the FTB Ultimine category, and set it to whatever you like.

The block tooltip

Look at any block and Jade puts a small panel on screen telling you what it is, which mod it came from, and often what tool it needs. When you hit an unfamiliar ore three hundred blocks down, this is what tells you whether it's worth mining.

Roughly how ores tier

You still start with stone, iron and diamond in the usual places at the usual depths. Beyond that the pack's ores sort loosely into:

  • Common metals — copper, tin, lead, silver, nickel, zinc and friends, throughout the overworld at ordinary depths. These feed nearly every machine recipe, so gather far more than feels necessary.
  • Deep and dimensional ores — the genuinely rare materials, at extreme depth or in other dimensions, usually behind a tool tier you have to build up to. Don't hunt these early; you'll just die a long way from home.
  • Grown resources — Mystical Agriculture lets you farm most materials as crops once you're established. Slower to set up, far faster afterwards, and the usual answer to "I need ten thousand of these."

Check before you dig. Press U on an ore or ingot to see everything it feeds into. Faster than reading six wikis.

Take a backpack

You will fill your inventory faster than you expect. A Sophisticated Backpack early on is worth more than better armour — it upgrades later to pick up, sort and even smelt what you mine.

Mine inside a claim if you're leaving machinery down there. Quarries, drills and anything automated only keep running in a force-loaded chunk, and unclaimed tunnels aren't protected from anything.

Getting around

The world is large and generated by four terrain mods at once — Terralith, Tectonic and Regions Unexplored in the Overworld, Nullscape in the End — so it's genuinely worth exploring. Set up fast travel early so exploring isn't a one-way trip.

Waystones

Waystones are the fast-travel network. Some generate naturally in villages and structures; you can also craft and place your own.

  1. Find or place one and right-click it to activate it.

    It's on your list permanently from then on.

  2. Right-click any other waystone to travel.

    Pick a destination from everything you've discovered.

  3. Put one at home first.

    Then activate every waystone you stumble across. The network is only as useful as the number of pins in it.

Paths make you faster

Walk on a path block and you move noticeably quicker — about 40% faster, and it applies the moment you step on. It works for horses too, and a horse pulling a cart drags the cart along at the same speed, so a proper road is the cheapest travel upgrade in the pack.

  1. Join up the places you actually walk between.

    House to mine, base to farm, spawn to your build. Short hops you make twenty times a day are worth more than one long scenic highway.

  2. Any path block counts.

    Plain dirt paths work, and so does everything from Macaw's Paths — stone paths, paving, flagstone, cobble walkways. Build whatever looks right; the speed is the same.

  3. Two blocks wide is plenty.

    Enough that you stay on it without steering. Widen it later if you are riding with someone.

Mobs get the speed boost too. Anything standing on your path moves faster, including whatever is chasing you. Light your roads properly — an unlit path is a fast lane for creepers as much as for you.

Building and decorating

There's a deep set of decoration mods here — Macaw's furniture, windows, doors, roofs, fences, paths, bridges, stairs and lights, plus FramedBlocks, which take on the appearance of anything else. If you enjoy the building side, browse these in the recipe viewer; there is far more available than the vanilla palette suggests.

Getting unstuck

  • Can't find a recipe? Search the item in the recipe viewer. If it has none it probably comes from a quest, a dungeon or a mob.
  • Machine not working? Nine times out of ten it's power, or an input on the wrong face. Look at the block to see its status panel.
  • Something feels broken? Say so in chat rather than working around it. Usually it's a known quirk with a one-line fix.
